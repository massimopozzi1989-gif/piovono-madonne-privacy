# Piovono Madonne - Informativa Privacy

Informativa pubblica per l'app Android `com.massimopozzi.piovonomadonne`,
pubblicata da MassimoPozzi e destinata a un pubblico maggiorenne (18+).

[Leggi l'informativa](https://massimopozzi1989-gif.github.io/piovono-madonne-privacy/)

## Contenuto

`index.html` e una pagina statica in italiano, senza JavaScript, cookie,
servizi di analisi o dipendenze esterne. Il sito e ospitato su GitHub Pages.
La pagina descrive i permessi Health Connect facoltativi, l'elaborazione locale,
i backup Android e le modalita di cancellazione dei dati dell'app.

Per visualizzarla localmente, aprire `index.html` in un browser.
Per aggiornamenti, modificare la pagina e pubblicare sul ramo `main`.
L'informativa integrata nell'app deve restare coerente con quella pubblica.

Assistenza: massimo.pozzi1989@gmail.com.

Questa repository contiene soltanto l'informativa, non il codice dell'app
o le sue chiavi di firma. Non viene concessa una licenza di riutilizzo.
